# Phases 2 and 3 — sketch

Not tickets. These are deliberately unticketed: a ticket marked `ready-for-agent` is a promise that it can be picked up and built, and these cannot be yet. They will look different once Phase 1 has been used for real — browsing the collection on a phone for a few weeks will change what editing needs to feel like.

Ticket them after Phase 1 ships, not before.

## Phase 2 — keeping the collection alive

**Add a Recipe.** Paste a URL, give it a name, pick Categories from the existing list rather than typing them. The Source is recognised from the host automatically, and a new one is created when the host is unfamiliar. This is what makes the collection grow again now that Pocket is gone.

**Edit a Recipe.** Correct a name — particularly the rough ones derived from URL slugs in ticket 02 — and change which Categories it belongs to.

**Soft delete and the recycle bin.** Deleting hides a recipe rather than destroying it, and a Deleted view restores anything. The bin is emptied deliberately. This exists because the collection is irreplaceable and deletion will happen one-handed, on a phone, in a kitchen.

**Tried and Favourite.** Mark what you have cooked, and which of those was worth repeating. Favourite implies Tried and setting one sets the other. Filter to Favourites for a reliable choice, or to never-Tried for something new.

## Phase 3 — tidying the shelf

**Rename and merge Categories.** `#kopřivy` loses its stray `#` everywhere at once. Two names for the same thing become one. New Categories can be added.

**Rename and merge Sources.** A shelf entry reads as a blog's real name rather than a domain, and duplicate blogs the import did not catch are joined by hand.

Both should show how many recipes a Category or Source holds before you change it.

## Known gaps, accepted

**No wishlist.** Favourite means proven and implies Tried, so there is no way to flag a recipe you are excited to try but have not made. Recorded in the spec as a deliberate gap. If it starts to bite, it is a new concept, not a loosening of Favourite.

## Further out

The random picker. Sources that are not websites — cookbooks, PDFs, emails, a scanned table of contents. Source was built as a curated entity in Phase 1 specifically so these fit without a migration.
